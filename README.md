# VariantAI

An AI-powered variant analysis project.

## Getting Started

This project uses [uv](https://github.com/astral-sh/uv) for dependency management.

```bash
# Install dependencies
uv sync

# Run the project
uv run python main.py
```

## Development

```bash
# Lint and format
uv run ruff check
uv run ruff format

# Run tests
uv run pytest
```
